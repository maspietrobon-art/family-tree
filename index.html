Carica data.enc su GitHub

  1. Il file data.enc è stato scaricato (di solito nella cartella Download).
  2. Apri il repository dell'app su github.com e scegli Add file → Upload files.
  3. Trascina data.enc: sostituisce quello vecchio. Premi Commit changes.
  4. Dopo circa un minuto gli altri dispositivi, riaprendo l'app, ricevono i dati aggiornati.

Il file è cifrato con la tua password: anche se il repository è pubblico, senza password non si legge.

Impostazioni

Le modifiche si salvano da sole su questo dispositivo. Per averle anche sugli altri, premi ⬆ GitHub: scarichi il file data.enc (cifrato con la tua password) e lo carichi nel repository al posto di quello vecchio. Il pulsante diventa arancione quando ci sono modifiche non ancora caricate.
